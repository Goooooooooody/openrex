# Security

Please don't report security problems in public issues. Report them privately
through GitHub instead: on the repository's **Security** tab, choose
**Report a vulnerability**. You'll get a reply there.

OpenRex talks to a Rex server, which runs your terminals, so problems worth
reporting include anything that lets a program in a terminal, a malicious
server, or another client make OpenRex do something you didn't ask for: run
commands, read or write files, open links, or reach the clipboard.

Problems in the Rex server itself belong with Superlogical, the makers of Rex.
